# 🚗 Exercício Abstract Factory - Fábrica de Carros

## 📚 Sobre o projeto

Este projeto foi desenvolvido como exercício prático de **Programação Orientada a Objetos (POO) em Java**, com o objetivo de estudar e aplicar o padrão de projeto **Abstract Factory**.

O sistema simula uma fábrica de carros capaz de produzir veículos de diferentes marcas.
